# Roadmap

## Gameplay-first 1.0

1. Preserve public pre-release 0.19.0d and source-bound 0.20.0a evidence.
2. Complete the minimal 0.22.0c Build 614 startup and strict-log boundary. Native
   Machine, farm, settlement-service, upgrade, and serialization behavior is
   inherited and is not replayed for reassurance.
3. Validate the 0.23.0b building operating-envelope and Fuel Station compatibility
   successor with one fresh-world registration, strict-log, toolbar, moved-owner,
   and attached-vehicle inspection.
4. Fix only demonstrated gameplay, balance, copy, presentation, or compatibility
   defects.
5. Freeze one deterministic 1.0 candidate.
6. Run independent, uncoached single-player campaigns on that exact archive.
7. Publish the tested bytes on GitHub Releases and COI Hub.

No additional gameplay domain belongs before this boundary. Public 0.22.0c is
frozen; 0.23.0a is a balance successor, not a new gameplay domain.

## Stabilization

After 1.0, prioritize compatibility with game updates, clear diagnostics, save
safety, documentation, and narrowly demonstrated balance corrections. Preserve
older release archives for players on supported game branches.

## Later directions

Potential later work includes civic knowledge infrastructure, bounded planetary
stewardship policies, and custom presentation. These are directions, not promises;
they must earn separate scope and must not destabilize the released core.

Recirculating aquaculture and insect bioconversion are also deferred. Either must
earn a native biological entity with growth, care, water, failure, and persistence;
neither may ship as an ordinary recipe that exists only to consume Feed.

A future art-focused release may replace borrowed compatible world-space building
representations with original models without changing gameplay contracts.

## Explicitly deferred

- Automatic factory placement or self-replication.
- Custom vehicle dispatch.
- Free-resource or positive recycling loops.
- Global machine-speed, yield, or reactor-output multipliers.
- Mandatory abandonment of conventional industry.
