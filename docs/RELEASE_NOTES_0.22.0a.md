# Recursive Industry 0.22.0a Playtest

This pre-release expands the physical AI economy into Data-only Fiber control,
directed processing, adaptive farming, and circular agrifood.

## Highlights

- 235 Fiber-free Direct bindings across nineteen specialist megafacilities.
- Twenty-four Stream-controlled cross-stage compositions on eleven owners.
- Access and Backbone Fiber, two Gateway deployment modes, and the Deployment
  Assurance Campus.
- Five directed refinery slates and production-scale Electronics III.
- Precision Irrigation plus native Greenhouse II and Chicken Farm upgrades.
- Four Stream-free Circular Agrifood recipes for formulated Eggs, cultured Meat,
  mycoprotein Trimmings, and Companion Provisions.
- An optional staffed Companion Animal Center that consumes provisions, returns
  Waste, and grants 0.6 Unity at full satisfaction.

## Install

This build requires Captain of Industry 0.8.7 and Trains expansion 1.0.0 or
newer. Supporter edition is optional.

**Start a new campaign.** Migration from earlier Recursive Industry pre-releases
is unsupported. An old placed-machine save can load with legacy molten-output
connections that continuously report incompatible products. Do not use an old
save to evaluate this playtest.

Download the attached `RecursiveIndustry-0.22.0a.zip`, not GitHub's automatic
source archives. Extract it into `%APPDATA%/Captain of Industry/Mods` and enable
Recursive Industry when creating the world.
