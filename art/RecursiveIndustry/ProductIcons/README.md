# Foundation product icons

This directory contains the original source and reviewed exports for Recursive
Industry's eight Foundation products.

- `masters/`: high-resolution source images.
- `exports/`: reviewed 512x512 RGBA images imported into Unity.
- `asset-manifest.json`: file hashes, runtime paths, and bundle identity.

The active set uses flat symbols designed to remain legible at 24 and 32 pixels.
The runtime bundle is `producticons_84e1` and contains no dependencies.
