# Security Policy

## Supported versions

Security fixes are applied to the latest public release. Pre-release source may
change without compatibility guarantees.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** feature for security-sensitive
reports. Do not open a public issue for suspected code execution, unsafe file
access, credential exposure, or malicious package behavior.

For ordinary crashes, compatibility problems, and gameplay defects, use the
public bug-report template.

Recursive Industry makes no network connections and does not intentionally read
or write files outside Captain of Industry and normal build/deployment paths. Hub
code-analysis findings should be reported when they appear inconsistent with
that boundary.
